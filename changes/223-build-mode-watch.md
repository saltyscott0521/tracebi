### Changed — Build mode is for watching, not instructing

- You instruct your agent in its chat; the app is where you watch it work. The
  notes box and in-app pins from the first Build mode are gone (the pins the
  agent resolves still show, with its answer).
- A **Changes** timeline: each time the agent saves, the figures that changed
  are listed (`kpi-mrr: $3,535 → $3,812`, `+1 figure`) and flash in the report.
  Pick an earlier entry to see the report as it was, then **Back to latest**.
  Versions are kept in memory for the visit; nothing is saved or sent.
- Pointing is still there, so "make this a line chart" means a specific figure.
