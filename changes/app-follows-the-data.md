### Changed

- **The sidebar follows the data**: Sources → Pipelines → Data model → Explore → Reports (was Report, Data model, Connectors, Refresh, Explore). *Connectors* is now **Sources** (a source is a connector), *Refresh* is **Pipelines**, *Report* is **Reports**. URLs are unchanged.
- Every one of those pages opens with a **"you are here" strip**: the whole chain in one line, this page marked and the others links, with what each step is for on hover.
- **Getting Started** opens with *How the pieces fit*: the five steps, each with the question it answers, what it means and where it lives in a project. The order and the words come from one list that the sidebar, the command palette and that page all read.
- The command palette lists the pages in the same order, each with its question and old name, so searching "connectors", "refresh" or "contract" (or "where is the data") still finds the page.
