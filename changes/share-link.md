### Added

- A share link for every report: `/r/<name>` (for example `/r/housing/affordability`) serves the last build as its own full page, so a phone opens it in the browser with live charts and calculators. The Reports page has **Full screen** and **Share** buttons for it. Access follows the server's auth like every other page: open on a server with no auth configured, and a login is needed when auth is on.
