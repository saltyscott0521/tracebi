- Every built package HTML ends with a plain-language **About this report**
  section (who / when when known, which model definitions, what the receipt
  is for). Authors who already place `data-tb-methodology` keep that as the
  home; otherwise the build adds a footer. Stated methodology notes still
  append after the author's own prose. The copy never claims a number is
  verified, reproduces, or correct.
