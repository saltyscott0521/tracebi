How these numbers were made

This file carries its trace: each figure names the query that produced it and a fingerprint of the result. tracebi verify re-runs those queries and checks whether the numbers still match the model.

the transform 'holdings' states: issuer and instrument type parsed from the prose position blob; sectors normalised from each administrator's spelling; money coerced from strings; exact double-booked positions deduped; rows with no keyable issuer dropped and counted

· rows(fact_holdings): a Schedule of Investments under 10 positions means the raw pull is truncated, not that the book shrank

· values(dim_rating): the CRM's ratings on the agency scale; an issuer it does not cover is Unrated, never dropped

measure 'fair_value': Total fair value

measure 'positions': Position count

measure 'mark': Fair value / cost

measure 'fv_share': Fair value as % of total

measure 'unrealized': Unrealized gain / loss

measure 'cost_basis': Total cost basis

measure 'fv_rank': Rank by fair value (1 = largest)

measure 'fv_cum_share': Cumulative % of total (largest first)

measure 'net_flow': Net cash flow (received less lent out)

measure 'flow_count': Number of cash flows
