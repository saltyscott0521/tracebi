# design/ — internal notes

The notes behind building TraceBi: design notes (one decision each, and why),
`strategy/` (intent, with dated targets), `pitfalls.md` (bugs hit in this repo,
and the rule that prevents each), and the UI audit baselines `scripts/ui_audit.py`
compares against. They are for people changing the framework.

Nothing here is published or served: the docs site and the app's Docs place read
only `docs/`, which is the handbook for people using TraceBi. Decisions are
recorded, dated, in `NOTES.md`; a note here holds the longer reasoning behind one.
